\# Google Cybersecurity Certificate: NIST SP 800-30 Risk Assessment Portfolio Project



\## 📌 Project Overview

This project demonstrates a cybersecurity risk assessment conducted on a vulnerable remote server environment. Completed as part of the \*\*Google Cybersecurity Professional Certificate\*\* program on Coursera, the objective was to utilize the \*\*NIST SP 800-30 Rev. 1\*\* framework to identify system vulnerabilities, estimate threat likelihood and impact, and deliver structured risk management recommendations for a small business.



\## 🏢 Scenario Context

\*Note: To respect Coursera's Honor Code, the raw curriculum prompt files and specific system documentation provided by Google have been omitted. The assessment context is outlined below:\*

\* \*\*Target System:\*\* A vulnerable remote server utilized by a small business.

\* \*\*The Task:\*\* Perform a qualitative risk assessment using foundational asset, threat, and vulnerability data to determine overall risk levels (Low, Medium, High).

\* \*\*Framework Used:\*\* NIST Special Publication 800-30 Revision 1 (Guide for Conducting Risk Assessments).



\## 📂 Repository Structure

\* \*\*`Risk\_Assessment\_Report.pdf`\*\* - The final vulnerability assessment deliverable containing the threat identification matrix, risk calculations, and actionable remediation strategies.



\## 🛡️ Skills Demonstrated

\* Risk Assessment \& Management Frameworks (NIST SP 800-30 Rev. 1)

\* Threat and Vulnerability Identification \& Analysis

\* Qualitative Risk Analysis (Likelihood vs. Impact Scoring)

\* Small Business Infrastructure Security Hardening
